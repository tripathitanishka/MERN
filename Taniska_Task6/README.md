# Laundry Services Website

## Project Description

A simple and responsive Laundry Services website created using HTML and CSS.

## Features

* Navigation bar with Home, Services, About Us, and Contact Us
* Hero section with laundry service information
* Attractive laundry service image
* Call-to-action button
* Responsive design for different screen sizes

## Technologies Used

* HTML5
* CSS3

## Files

* `index.html` - Main webpage
* `style.css` - Styling and layout

## How to Run

1. Download or clone the project.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser.
